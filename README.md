# Artist's Data

Sanatçılar (oyuncular ve müzisyenler) için yayın gecesi X analizi: tweet sayıları, görüntülenme, beğeni, olumlu/olumsuz yorum oranı ve gündem.

- Hayran girişi: özet veriler
- Ekip girişi (sanatçı, menajer, yapım): davet koduyla, tüm istatistikler. Ekip verisi davet koduyla şifrelenmiştir.

iPhone: Safari'de aç → Paylaş → Ana Ekrana Ekle.
